Panel reference

Choose a panel below for visual examples, its settings, and how it behaves.

Display preferences are best-effort: panels silently hide optional information that does not fit, preserving the settings so it can return when space permits. Limited space does not produce a configuration warning. Invalid settings still produce errors, and warning, critical, stale and unavailable state indications remain active.

Panel Purpose
Channel output Channel outputs with automatically matched stick-trim arrows.
Chart Armed-time history with up to three overlaid traces and raw recorded extrema.
Flight counter Shared flight detection and GV9 count.
Flight mode The active EdgeTX flight mode.
Flight timer An EdgeTX model timer.
Host diagnostics Troubleshooting report on the widget, theme, panels, and sources.
Link status Link quality, signal strength, and optional RF details.
Metric Up to three numeric readings, including telemetry and global variables.
Model identity Model name and picture.
Navigation GPS position, distance from home, and bearing toward the model.
RX battery Aircraft cell or pack voltage.
Service probe Troubleshooting view of one shared data service.
State Up to three readings selected by ordered switch conditions.
Trim Aileron, elevator, and rudder trims.
TX battery TX battery voltage and an optional voltage-based estimate.

Using the panel settings

Each panel page lists the settings exactly as they appear when you tap a panel's gear in the on-radio editor. The controls behave the same way in every panel:

Control How it works
Choice Opens a list of the allowed values.
Number Steps by the increment listed on the panel page. Optional numbers have one extra step below their lowest value, shown as a word such as Off, Sensor, or Auto instead of a number. Stepping down to it clears the setting so the panel's fallback applies.
Text Opens the keyboard. Clearing an optional text restores its default, such as the source name.
Source, Switch, Timer Opens the standard EdgeTX picker. Sources that Lua cannot read are rejected with a message.
Entry rows Panels with lists, such as Metric, show one row per entry with a short summary. Tap a row to open that entry's settings.
+ Adds an entry at the bottom, copied from the last entry. It is unavailable when the list is full.
Remove entry Inside an entry, deletes it. A panel keeps at least its minimum number of entries.
Remove panel Deletes the panel from the screen.

Press RTN or tap outside a settings dialog to go back one level. Changes stay in your draft until you save the layout.

To add a screen, see Add a dashboard. To arrange panels, see Edit a dashboard on the radio. Arming, flight detection, session reset, and flight-status output are Model settings, not normal panel settings. Legacy panel arm controls may still appear on older layouts until model arming is saved.
